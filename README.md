## Projektidee
In diesem Projekt untersuchen wir die Entwicklung der Sterblichkeitsrate von Kindern in den ersten fünf Lebensjahren in verschiedenen Ländern zwischen 1990 und 2024. Mithilfe von Python und Pandas möchten wir die zeitliche Entwicklung sowie die Unterschiede zwischen den Ländern analysieren.
